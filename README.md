# Surreal Italo‑Disco Short Video Ideas Generator

Generate 5 concise concepts (30–60 seconds) that are always:

- Surreal, liminal, nostalgic
- Aesthetic blend: Italo‑disco × Sci‑Fi × Kitsch/Camp

## Run locally

Open `index.html` in any browser. No build step or server required.

## Usage

- Type an optional seed (a vibe, object, or scene) and click "Generate 5 ideas".
- Or click "Surprise me" for fully random ideas.
- Results are deterministic per seed (seeded PRNG), so the same seed yields the same 5 titles.

## Creative constraints (always enforced)

- Themes: surreal, liminal, nostalgic
- Aesthetic: Italo‑disco × Sci‑Fi × Kitsch/Camp
- Duration: each concept is scoped for 30–60 seconds

Your exact results will vary, but a single idea card looks like:

