# Surreal GenAI Video Ideas Generator

A web application that generates surreal, liminal, and nostalgic video ideas with italodisco, sci-fi, kitsch, and camp aesthetics.

## Features

- **Surreal Themes**: Always generates ideas that are surreal, liminal, and nostalgic
- **Aesthetic Mix**: Combines italodisco, sci-fi, kitsch, and camp elements
- **Custom Input**: Accept user prompts or generate random ideas
- **5 Ideas Per Generation**: Always provides exactly 5 video ideas
- **30-60 Second Duration**: All ideas are designed for short-form content
- **Responsive Design**: Works on desktop and mobile devices

## Usage

1. Open `index.html` in a web browser
2. Enter a concept or leave blank for random inspiration
3. Click "GENERATE" to get 5 surreal video ideas
4. Each idea includes a title, description, and duration

## Examples

The app can generate ideas like:
- A tape recorder that records your dreams and creates a matching mixtape when you wake up
- Old ladies dating muscular android gigolos
- Disco parties in liminal nostalgic surreal settings

## Technical Details

- **Frontend**: HTML5, CSS3, JavaScript (ES6+)
- **Styling**: Custom CSS with neon effects, gradients, and animations
- **Fonts**: Orbitron (futuristic) and Space Mono (monospace)
- **Responsive**: Mobile-first design with flexible layouts

## Aesthetic Elements

- **Surreal**: Dreamlike, impossible, and mind-bending concepts
- **Liminal**: In-between spaces, thresholds, and transitional moments
- **Nostalgic**: Childhood memories, past eras, and sentimental feelings
- **Italodisco**: 1970s-80s electronic dance music aesthetic
- **Sci-Fi**: Futuristic technology, space, and advanced concepts
- **Kitsch**: Deliberately tacky, campy, and over-the-top elements
- **Camp**: Exaggerated, theatrical, and performative style
