# ✨ Surreal Video Ideas Generator ✨

A beautiful, retro-futuristic web app that generates surreal video concepts for GenAI projects.

## 🎬 Features

- **Generate 5 unique video ideas** based on optional user input
- **Surreal, liminal, nostalgic themes** every time
- **Italodisco, sci-fi, kitsch, camp aesthetic**
- All ideas designed for **30-60 second videos**

## 🚀 How to Use

1. Open `index.html` in your web browser
2. (Optional) Enter a concept or theme in the input field
3. Click "Generate Ideas" to create 5 unique video concepts
4. Generate as many times as you want for endless inspiration!

## 🎨 The Rules

Every generated idea follows these constraints:
- **Themes:** Surreal, Liminal, Nostalgic
- **Aesthetic:** Italodisco, Sci-Fi, Kitsch, Camp
- **Duration:** 30-60 seconds max

## 💡 Example Ideas

- A tape recorder that records your dreams and creates a matching mixtape when you wake up
- Old ladies dating muscular androids gigolos
- Disco parties in liminal nostalgic surreal settings
- Holographic fortune tellers lost in an abandoned mall filled with neon lights and fog machines
- Chrome-plated flamingos racing through a cosmic laundromat where memories are washed

## 🎵 Aesthetic Reference

The app embraces:
- **Italodisco** vibes (synthwave, neon, retro)
- **Sci-Fi** elements (chrome, holograms, futurism)
- **Kitsch** sensibility (deliberately tacky, colorful, playful)
- **Camp** spirit (theatrical, knowing, excessive)

## 🌟 Running the App

Simply open `index.html` in any modern web browser. No installation or build process required!

Or run a local server:
```bash
python3 -m http.server 8000
```

Then visit `http://localhost:8000` in your browser.
