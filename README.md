# Cult Cinema Curator

A minimalist single-page app that celebrates the golden era of giallo, poliziesco, Italian erotica, and Hammer horror (1967&ndash;1981).

## Features

- **Instant Picks** &mdash; Tap a button to surface five random deep-cut recommendations from a hand-curated catalogue.
- **Mood Matcher Quiz** &mdash; Answer five questions and receive five films aligned with your desired tone, pace, setting, menace, and aftertaste.
- **Descriptive Capsules** &mdash; Every recommendation includes a succinct blurb plus genre badges for quick scanning.

## Getting Started

1. Open `index.html` in your browser, or serve the directory with a static file server.
2. Click **Suggest 5 Films** for immediate inspiration, or complete the quiz for tailored suggestions.

## Development Notes

- All titles are constrained to releases between 1967 and 1981.
- Quiz scoring blends mood tags with genre weighting to keep results thematically coherent.
- No build tooling is required; the experience runs entirely client-side.
